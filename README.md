# Password Strength Checker

## About the Project
This is a simple Python program for ICT Assignment 1.

## What the Program Does
- Checks the length of a password.
- Checks for uppercase and lowercase letters.
- Checks for numbers and special characters.
- Displays whether a password is weak, medium, or strong.

## Programming Language
Python
